Ajoutez un client une seule fois et réutilisez ses coordonnées sur chaque facture.

1. Ouvrez **Clients** et cliquez sur **New client**. Vous pouvez aussi utiliser les actions rapides → **New client**.
2. Choisissez **Client type** (entreprise ou particulier) et saisissez le nom. Seul le nom est obligatoire.
3. Sous **Address**, renseignez la rue, le numéro, le code postal, la ville et le pays. L’adresse est nécessaire pour émettre une facture à ce client.
4. Si vous le souhaitez, ajoutez **VAT / UID number** et le numéro d’immatriculation de l’entreprise. Sous **Billing defaults**, définissez la langue des documents, la devise et les conditions de paiement.
5. Cliquez sur **Add client**. Pour modifier ses données ultérieurement, ouvrez le client et cliquez sur **Edit**.

## Bon à savoir

- Un client dont l’adresse est incomplète apparaît comme brouillon. Vous pouvez préparer des factures pour lui, mais pas les émettre.
- Le menu **More actions** (…) du client permet de le désactiver pour le masquer dans les listes de sélection. Les propriétaires et administrateurs peuvent aussi le supprimer depuis ce menu.
