Les clients peuvent demander une mise à jour de leurs coordonnées depuis le portail ; vous décidez de l’accepter ou non.

Le portail client, et donc les demandes de modification, nécessite **Business**.

1. Lorsqu’un client demande dans le portail de modifier ses coordonnées (nom, e-mail de facturation, téléphone, adresse, numéro de TVA ou d’immatriculation), les propriétaires et administrateurs reçoivent une notification.
2. Ouvrez le client. Une bannière présente les modifications demandées.
3. Cliquez sur **Approve** pour les appliquer, ou sur **Reject** pour les refuser.

## Bon à savoir

- Seuls les propriétaires et administrateurs peuvent statuer sur les demandes de modification.
- Les factures déjà émises conservent les anciennes coordonnées.
