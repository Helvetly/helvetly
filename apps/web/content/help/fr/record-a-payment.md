Lorsque vous recevez de l’argent, enregistrez-le sur la facture pour toujours connaître le solde dû.

1. Ouvrez la facture et cliquez sur **Enregistrer le paiement**. Cette action figure aussi dans le menu **…** de la ligne dans la liste.
2. Saisissez **Montant** et la date **Payé le**, ou cliquez sur **Mark fully paid today**.
3. Si vous le souhaitez, choisissez **Mode de paiement** et ajoutez une note visible uniquement par votre équipe.
4. Cliquez sur **Enregistrer le paiement**. Le statut passe à Paid lorsqu’il ne reste rien à payer.

## Bon à savoir

- Le montant ne peut pas dépasser le solde dû, et la date ne peut pas être future.
- Pour corriger une erreur, ouvrez l’onglet **Paiements** et supprimez le paiement.
- Le PDF émis et son code QR conservent le montant initial. Après un paiement partiel, le client peut consulter le solde dans le portail Business. Pour un virement, il saisit ce solde dans son e-banking.
