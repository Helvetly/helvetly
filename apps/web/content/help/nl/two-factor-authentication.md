Tweefactorauthenticatie voegt bij elke aanmelding een code van je telefoon toe.

1. Ga naar **Settings → Account settings → Two-factor authentication** en klik op **Turn on**.
2. Scan de code met een authenticator-app zoals 1Password, Google Authenticator of Authy.
3. Voer de zescijferige **Code from the app** in en klik op **Turn on**.
4. Bewaar je herstelcodes. Met elke code kun je één keer aanmelden als je je telefoon verliest.

## Goed om te weten

- Klik op **Turn off** en voer een appcode of herstelcode in om dit uit te schakelen.
- Herstelcodes worden maar één keer getoond; bewaar ze dus veilig.
