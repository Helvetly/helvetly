Neben regulären Rechnungen verarbeitet Helvetly alle gängigen Rechnungsdokumenttypen.

Gutschriften, Lastschriften und korrigierte Rechnungen benötigen **Pro** oder **Business**; die anderen Typen sind in jedem Plan enthalten.

1. Um eine Teilrechnung, Vorauszahlungsrechnung, Proforma-Rechnung oder Gutschriftsrechnung zu erstellen, klicken Sie auf den Pfeil neben **New invoice** auf **Invoices** und wählen Sie den Typ aus.
2. Eine Gutschrift, Lastschrift oder korrigierte Rechnung erfolgt immer ausgehend von einer ausgestellten Rechnung. Öffnen Sie diese Rechnung, öffnen Sie das Menü **…** und wählen Sie **Create credit note**, **Debit note** oder **Correct**. Es öffnet sich ein Entwurf, den Sie anpassen und ausstellen können.
3. Um ein Proforma in eine echte Rechnung umzuwandeln, öffnen Sie es und klicken Sie auf **Convert to invoice** oder **Convert to prepayment**. Das Proforma selbst bleibt so wie es ist.
4. Um eine bezahlte Vorauszahlung abzuziehen, erstellen Sie eine normale Rechnung für denselben Kunden und wählen Sie die Vorauszahlung unter dem Beleg aus. Er wird vom fälligen Betrag abgezogen.
5. Für jeden Typ gibt es oben in **Invoices** eine eigene Registerkarte: Rechnungen, Teilrechnungen, Vorauszahlungen, Belastungsanzeigen, Korrekturen, Gutschriften, Proforma und Gutschrift.

## Gut zu wissen

- Eine korrigierte Rechnung ersetzt das Original, sobald Sie sie ausgestellt haben, und alle Zahlungen werden übernommen.
- Eine selbst in Rechnung gestellte Rechnung wird von Ihnen ausgezahlt. Sie können Selbstfakturierungsvereinbarungen auf der Registerkarte **Overview** des Kunden unter **Self-billing agreements** erfassen.
