Stecken Sie fest, haben Sie einen Fehler gefunden oder haben Sie eine Idee? So erreichen Sie uns.

1. Klicken Sie unten in der Seitenleiste auf **Hilfe und Feedback** oder wählen Sie es in Ihrem Namensmenü oder in den Schnellaktionen aus.
2. Für eine Anleitungsfrage klicken Sie oben auf **Ask Heidi**. Das Bedienfeld von Heidi wird geöffnet.
3. Um dem Team etwas mitzuteilen, wählen Sie **Ein Problem melden** oder **Schlagen Sie eine Idee vor**.
4. Schreiben Sie einen **Beschreibung**. Sie können auch **Screenshots** hinzufügen (ablegen, einfügen oder durchsuchen): bis zu 5 PNG-, JPEG- oder WebP-Bilder, jeweils 5 MB.
5. Klicken Sie auf **Feedback senden**.

## Gut zu wissen

- Ihr Konto, Ihr Arbeitsbereich und die Seite, auf der Sie sich befinden, sind in Ihrer Nachricht enthalten, Ihr Bildschirm wird jedoch nicht aufgezeichnet.
- Entfernen Sie alle privaten Informationen aus Screenshots, bevor Sie sie senden.
