Helvetly hat keine Passwörter. Wählen Sie die für Sie passenden Anmeldemethoden.

1. Gehen Sie zu **Settings → Account settings → Sign-in methods**.
2. **Email code** sendet einen 6-stelligen Code an Ihre E-Mail.
3. Verbinden Sie **Google** für die Anmeldung mit einem Klick oder klicken Sie auf **Disconnect**, um es zu entfernen.
4. Klicken Sie unter **Passkeys** auf **Add passkey**, um sich mit Ihrem Fingerabdruck, Ihrem Gesicht oder Ihrer Geräte-PIN anzumelden. Entfernen Sie einen Hauptschlüssel mit dem entsprechenden Symbol zum Entfernen.

## Gut zu wissen

- Es müssen keine Passwörter gespeichert oder zurückgesetzt werden.
