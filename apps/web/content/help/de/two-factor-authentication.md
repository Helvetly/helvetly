Bei der Zwei-Faktor-Authentifizierung wird bei jeder Anmeldung ein Code von Ihrem Telefon hinzugefügt.

1. Gehen Sie zu **Einstellungen → Kontoeinstellungen → Zwei-Faktor-Authentifizierung** und klicken Sie auf **Einschalten**.
2. Scannen Sie den Code mit einer Authentifizierungs-App wie 1Password, Google Authenticator oder Authy.
3. Geben Sie die 6-stellige Zahl **Code aus der App** ein und klicken Sie auf **Einschalten**.
4. Speichern Sie Ihre Wiederherstellungscodes. Jeder meldet Sie einmal an, falls Sie Ihr Telefon verlieren.

## Gut zu wissen

- Um es zu deaktivieren, klicken Sie auf **Ausschalten** und geben Sie einen Code aus der App oder einen Wiederherstellungscode ein.
- Wiederherstellungscodes werden nur einmal angezeigt. Bewahren Sie sie daher an einem sicheren Ort auf.
