Durch das Stornieren wird eine ausgestellte Rechnung storniert, sodass nichts mehr geschuldet wird.

Für die Stornierung einer ausgestellten Rechnung ist **Pro** oder **Business** erforderlich. In Basic können Sie einen Entwurf weiterhin bearbeiten oder löschen.

1. Öffnen Sie die ausgestellte Rechnung und öffnen Sie das Menü **…**.
2. Wählen Sie **Void** und bestätigen Sie mit **Void invoice**.
3. Es wird eine volle Gutschrift ausgestellt und es besteht keine Schuld mehr.

## Gut zu wissen

- Nur Eigentümer und Administratoren können Rechnungen stornieren und nur öffnen, ohne dass Zahlungen oder Gutschriften vorliegen.
- Die Stornierung kann nicht rückgängig gemacht werden.
- Entwürfe werden nicht ungültig: Verwenden Sie stattdessen **Delete draft**. Ein Entwurf hat keine Nummer, daher geht bei Ihrer Nummerierung nichts verloren.
