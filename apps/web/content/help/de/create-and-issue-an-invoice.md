Erstellen Sie einen Entwurf, überprüfen Sie das PDF und geben Sie es aus, wenn Sie bereit sind.

1. Gehen Sie zu **Invoices** und klicken Sie auf **New invoice**. Sie können auch Schnellaktionen oder die Schaltfläche **Invoice** auf einem Client verwenden.
2. Klicken Sie unter **Bill to** auf **Choose a client**.
3. Überprüfen Sie die Daten **Issue date**, **Due date** und **Service** und fügen Sie bei Bedarf einen **Reference** (z. B. eine Bestellnummer) hinzu.
4. Fügen Sie Zeilen mit **Add line** (oder drücken Sie die Eingabetaste) oder **Add from catalogue** hinzu. Über dem Dokument können Sie **Currency**, **Document language** und **VAT** einstellen. Sie können auch einen **Discount**, eine Einleitung, eine Fusszeile und einen **Internal note** hinzufügen, der nie gedruckt wird.
5. Der Entwurf speichert von selbst und ⌘S speichert sofort. Klicken Sie auf **Preview** (⌘P), um das PDF anzuzeigen.
6. Klicken Sie auf **Issue invoice** und bestätigen Sie. Die Rechnung erhält die nächste Nummer und ihr PDF wird gespeichert.

## Gut zu wissen

- Die Ausgabe kann nicht rückgängig gemacht werden. Eine ausgestellte Rechnung kann nicht bearbeitet werden, sodass Korrekturen über eine Gutschrift oder Korrektur erfolgen.
- Wenn etwas fehlt, listet Helvetly mit einem Link auf, was behoben werden muss, z. B. **Open invoice settings** oder **Complete the client**.
