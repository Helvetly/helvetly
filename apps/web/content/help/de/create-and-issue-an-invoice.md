Erstellen Sie einen Entwurf, überprüfen Sie das PDF und geben Sie es aus, wenn Sie bereit sind.

1. Gehen Sie zu **Rechnungen** und klicken Sie auf **Neue Rechnung**. Sie können auch Schnellaktionen oder die Schaltfläche **Rechnung** auf einem Client verwenden.
2. Klicken Sie unter **Rechnung an** auf **Wählen Sie einen Kunden**.
3. Überprüfen Sie die Daten **Ausstellungsdatum**, **Fälligkeitsdatum** und **Dienst** und fügen Sie bei Bedarf einen **Referenz** (z. B. eine Bestellnummer) hinzu.
4. Fügen Sie Zeilen mit **Zeile hinzufügen** (oder drücken Sie die Eingabetaste) oder **Aus Katalog hinzufügen** hinzu. Über dem Dokument können Sie **Währung**, **Dokumentsprache** und **MWST** einstellen. Sie können auch einen **Rabatt**, eine Einleitung, eine Fusszeile und einen **Interner Hinweis** hinzufügen, der nie gedruckt wird.
5. Der Entwurf speichert von selbst und ⌘S speichert sofort. Klicken Sie auf **Vorschau** (⌘P), um das PDF anzuzeigen.
6. Klicken Sie auf **Issue invoice** und bestätigen Sie. Die Rechnung erhält die nächste Nummer und ihr PDF wird gespeichert.

## Gut zu wissen

- Die Ausgabe kann nicht rückgängig gemacht werden. Eine ausgestellte Rechnung kann nicht bearbeitet werden, sodass Korrekturen über eine Gutschrift oder Korrektur erfolgen.
- Wenn etwas fehlt, listet Helvetly mit einem Link auf, was behoben werden muss, z. B. **Open invoice settings** oder **Vervollständigen Sie den Client**.
