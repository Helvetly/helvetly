Fügen Sie einen Kunden einmal hinzu und verwenden Sie seine Daten auf jeder Rechnung wieder.

1. Gehen Sie zu **Clients** und klicken Sie auf **New client**. Sie können auch Schnellaktionen → Neuer Kunde verwenden.
2. Wählen Sie **Client type** (Firma oder Person) und geben Sie den Namen ein. Es ist lediglich der Name erforderlich.
3. Geben Sie unter **Address** Strasse, Nummer, Postleitzahl, Stadt und Land ein. Sie benötigen die Adresse, bevor Sie diesem Kunden eine Rechnung ausstellen können.
4. Wenn Sie möchten, fügen Sie **VAT / UID number** und die Handelsregisternummer hinzu. Legen Sie unter **Billing defaults** die Dokumentsprache, Währung und Zahlungsbedingungen fest.
5. Klicken Sie auf **Add client**. Um es später zu ändern, öffnen Sie den Client und klicken Sie auf **Edit**.

## Gut zu wissen

- Ein Kunde ohne vollständige Adresse wird als Entwurf angezeigt. Sie können Rechnungen dafür erstellen, aber nicht ausstellen.
- Im **More actions** (…)-Menü des Clients können Sie den Client deaktivieren, wodurch er vor Pickern verborgen bleibt. Besitzer und Administratoren können es dort auch löschen.
