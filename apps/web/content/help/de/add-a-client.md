Fügen Sie einen Kunden einmal hinzu und verwenden Sie seine Daten auf jeder Rechnung wieder.

1. Gehen Sie zu **Kunden** und klicken Sie auf **Neuer Kunde**. Sie können auch Schnellaktionen → Neuer Kunde verwenden.
2. Wählen Sie **Clienttyp** (Firma oder Person) und geben Sie den Namen ein. Es ist lediglich der Name erforderlich.
3. Geben Sie unter **Adresse** Strasse, Nummer, Postleitzahl, Stadt und Land ein. Sie benötigen die Adresse, bevor Sie diesem Kunden eine Rechnung ausstellen können.
4. Wenn Sie möchten, fügen Sie **Umsatzsteuer-/UID-Nummer** und die Handelsregisternummer hinzu. Legen Sie unter **Abrechnungsvorgaben** die Dokumentsprache, Währung und Zahlungsbedingungen fest.
5. Klicken Sie auf **Client hinzufügen**. Um es später zu ändern, öffnen Sie den Client und klicken Sie auf **Bearbeiten**.

## Gut zu wissen

- Ein Kunde ohne vollständige Adresse wird als Entwurf angezeigt. Sie können Rechnungen dafür erstellen, aber nicht ausstellen.
- Im **Weitere Aktionen** (…)-Menü des Clients können Sie den Client deaktivieren, wodurch er vor Pickern verborgen bleibt. Besitzer und Administratoren können es dort auch löschen.
