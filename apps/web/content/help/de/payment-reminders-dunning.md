Lassen Sie Helvetly überfällige Rechnungen höflich und pünktlich für Sie erledigen.

Automatische Erinnerungen erfordern **Pro** oder **Business**; jede gesendete Erinnerung verwendet eine automatisierte Aktion.

1. Gehen Sie zu **Einstellungen → Rechnungen → Mahnwesen** und aktivieren Sie **Erinnerungen automatisch versenden**.
2. Richten Sie bis zu drei Ebenen ein. Stellen Sie für jede Ebene Folgendes ein: **Gesendet**, optional **Gebühr** und **Eigener Text**. Sie können auch **Verzugszinsen** festlegen.
3. Überfällige Rechnungen erhalten dann jede Stufe einmal per E-Mail an die Rechnungsadresse des Kunden, mit einer QR-Rechnung über den Gesamtbetrag.
4. Um eine Rechnung zu bearbeiten, öffnen Sie sie. Mit der Erinnerungskarte können Sie **Send … now**, **Pause** oder **Fortsetzen** verwenden. Jeder gesendete Brief wird als PDF geöffnet.
5. Um einen Client auszulassen, bearbeiten Sie den Client und deaktivieren Sie **Zahlungserinnerungen**.

## Gut zu wissen

- Das Mahnrecht gilt nur für Rechnungen ohne Teilzahlungen.
- Sie können eine Erinnerung auch dann manuell senden, wenn das automatische Senden deaktiviert ist.
