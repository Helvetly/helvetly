Let Helvetly chase overdue invoices for you, politely and on time.

Automatic reminders need **Pro** or **Business**; each reminder sent uses one automated action.

1. Go to **Settings → Invoices → Dunning** and turn on **Send reminders automatically**.
2. Set up to three levels. For each level, set when it is **Sent**, an optional **Fee** and **Own text**. You can also set **Default interest**.
3. Overdue invoices then get each level once, by email to the client's billing address, with a QR bill for the total.
4. To act on one invoice, open it. The reminders card lets you **Send … now**, **Pause** or **Resume**. Each sent letter opens as a PDF.
5. To leave a client out, edit the client and turn off **Payment reminders**.

## Good to know

- Dunning applies only to invoices without instalments.
- You can send a reminder by hand even when automatic sending is off.
