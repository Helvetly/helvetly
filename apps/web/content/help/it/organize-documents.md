Conserva tutti i file aziendali in un unico posto ordinato.

1. Vai a **Documenti** e fai clic su **Carica** oppure trascina i file sulla pagina.
2. Per creare una cartella, fai clic su **Crea → Nuova cartella**.
3. Fai clic con il tasto destro su un file per **Scarica**, **Rinomina** (F2), **Sposta in…**, **Copia in…**, **Taglia** o **Sposta nel Cestino**.
4. Aggiungi le cartelle ai preferiti per ritrovarle in **Speciale** nel pannello sinistro. Usa **Tipi**, **Recenti**, **Modelli** e **Firme** per filtrare.
5. Usa la casella di ricerca e i pulsanti **Filtra** e **Ordina** per trovare i file.

## Da sapere

- Puoi anche caricare file nella scheda **File** di un cliente. Vengono collegati a quel cliente.
- Raggruppa i file per tipo, anno o cliente senza spostarli. Scarica la vista filtrata in formato ZIP. Una notifica segnala quando gli archivi più grandi sono pronti. Restano disponibili per sette giorni.
