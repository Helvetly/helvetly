Conserva tutti i file aziendali in un unico posto ordinato.

1. Vai a **Documents** e fai clic su **Upload** oppure trascina i file sulla pagina.
2. Per creare una cartella, fai clic su **Create → New folder**.
3. Fai clic con il tasto destro su un file per **Download**, **Rename** (F2), **Move to…**, **Copy to…**, **Cut** o **Move to Trash**.
4. Aggiungi le cartelle ai preferiti per ritrovarle in **Starred** nel pannello sinistro. Usa **Types**, **Recent**, **Templates** e **Signatures** per filtrare.
5. Usa la casella di ricerca e i pulsanti **Filter** e **Sort** per trovare i file.

## Da sapere

- Puoi anche caricare file nella scheda **Files** di un cliente. Vengono collegati a quel cliente.
