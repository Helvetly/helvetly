Bestäm vad Helvetly ska meddela dig om och var.

1. Klicka på **Notifications** i sidofältet för att öppna klockan med de senaste händelserna, eller klicka på **All notifications** för hela sidan.
2. Klicka på **Mark all as read** på sidan Notifications.
3. Gå till **Settings → Account settings → Notifications** för att välja vad som når dig via mejl och i klockan. Markera per händelse och klicka på **Save changes**.

## Bra att veta

- Ägare och administratörer kan aktivera **Daily e-mail digest** för uppdrag i sidmenyn på **Engagements**.
