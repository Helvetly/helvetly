Helvetly har inga lösenord. Välj de inloggningssätt som passar dig.

1. Gå till **Settings → Account settings → Sign-in methods**.
2. **Email code** skickar en 6-siffrig kod till din mejladress.
3. Anslut **Google** för inloggning med ett klick eller klicka på **Disconnect** för att koppla bort.
4. Under **Passkeys** klickar du på **Add passkey** för att logga in med fingeravtryck, ansikte eller enhetens PIN-kod. Ta bort en passnyckel med dess borttagningsikon.

## Bra att veta

- Det finns inga lösenord att komma ihåg eller återställa.
