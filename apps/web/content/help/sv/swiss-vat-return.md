Helvetly förbereder siffrorna för den schweiziska momsdeklarationen (MWST) och filen för import i ESTV ePortal.

Att förbereda momsdeklarationer kräver **Pro** eller **Business**. Moms på fakturor beräknas i varje plan.

1. Gå till **Books → VAT return**.
2. I momsinställningarna anger du metod (**Effective method** eller **Net tax rate method**), periodlängd och grund (**Agreed** eller **Received consideration**) och sparar. För nettoskattesatser lägger du till dina **Approved net tax rates**.
3. Välj **Period** och kontrollera siffrorna och eventuella varningar.
4. Klicka på **Export → ESTV file (XML)** för att få eCH-0217-filen. Samma meny erbjuder **PDF summary** och **CSV**.
5. Öppna MWST-Abrechnung pro → Import i ESTV ePortal och ladda upp filen.

## Bra att veta

- Siffrorna kommer från utfärdade fakturor och bokförda utgifter.
- Helvetly lämnar inte in deklarationen åt dig.
- Bara ägare och administratörer kan ändra momsinställningarna.
