# Security

Please do not report security vulnerabilities in public issues, discussions or pull requests.

Report them privately through GitHub: on this repository's **Security** tab, choose **Report a vulnerability**
(GitHub private vulnerability reporting). Include what is affected, how to reproduce it and what an attacker could
achieve. Do not access data that is not yours and do not degrade a service while testing.

Helvetly is not released yet: only the latest `main` is maintained, and there is no bug bounty.
